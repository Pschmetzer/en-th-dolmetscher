## ส่วนต่าง ๆ

หน้าเว็บมี 4 แท็บ ระบบจำแท็บที่คุณใช้ล่าสุด

| แท็บ | มีอะไรบ้าง |
|---|---|
| พูด | เลือกว่าใครพูด พิมพ์แทนการพูด **หน้าจอสองคน** (แต่ละฝั่งพิมพ์ภาษาของตัวเอง) และรายการสนทนา |
| สมุดวลี | 201 หัวข้อพร้อมบัตรแสดง (ข้อความไทยตัวใหญ่ อ่านออกเสียงได้) ตัวเลขและราคา (พร้อมเครื่องคิดอัตราแลกเปลี่ยน เวลา และเบอร์โทรเป็นคำไทย) พจนานุกรม; ปุ่มเต่าอ่านซ้ำช้า ๆ |
| บัตร | บัตรของฉัน (โรงแรม ที่อยู่) บัตรภูมิแพ้และฉุกเฉิน (แชร์เป็นรูปภาพได้) |
| เรียน | บัตรคำจากประโยคที่คุณติดดาว |

## ออฟไลน์และการติดตั้ง

เปิดหน้านี้หนึ่งครั้งขณะมีอินเทอร์เน็ต แล้วสมุดวลีและบัตรแสดงจะใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต ส่วนการแปลและการรู้จำเสียงต้องใช้เครือข่ายเสมอ เลือก "เพิ่มลงในหน้าจอหลัก" เพื่อใช้เหมือนแอป

## ข้อมูลที่ออกจากอุปกรณ์

- การรู้จำเสียงทำโดยเบราว์เซอร์: Chrome ส่งเสียงไปที่ Google ส่วน Safari ส่งไปที่ Apple หน้านี้จะถามก่อนใช้ไมโครโฟนครั้งแรก
- ข้อความที่รู้จำหรือพิมพ์จะถูกส่งไปแปลที่ Google Translate (สำรอง: MyMemory)
- ข้อความที่แชร์เข้ามาจากแอปอื่นจะถูกแปลหลังจากคุณแตะ "แปล" เท่านั้น
- ข้อมูลอื่นทั้งหมด (การตั้งค่า บัตร สถานะการเรียน บัตรภูมิแพ้) อยู่ในเบราว์เซอร์นี้เท่านั้น ดูเพิ่มที่ [PRIVACY-SHORT.md](PRIVACY-SHORT.md)

## ภาษาและคุณภาพ

ประโยคภาษาอังกฤษและไทยมาพร้อมหัวข้อ ประโยคภาษาไทยยังไม่ได้รับการตรวจโดยเจ้าของภาษา ภาษาอื่นแปลด้วยเครื่องเมื่อต้องใช้ครั้งแรกและมีป้ายกำกับ
