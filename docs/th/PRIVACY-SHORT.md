## Mac: อยู่ในเครื่อง

- เสียงจากไมโครโฟนประมวลผลในหน่วยความจำเท่านั้น ไม่บันทึกและไม่ส่งออก
- การรู้จำเสียงพูด (Whisper) ทำงานบน Mac โมเดลดาวน์โหลดครั้งเดียวจาก Hugging Face
- โปรไฟล์เสียงเป็นข้อมูลชีวมิติ เก็บไว้เฉพาะที่ `~/Library/Application Support/Dolmetscher/profiles/` อ่านได้เฉพาะคุณ ไม่ถูกส่งออก และลบได้ในแอป
- คีย์ API ของ Claude เก็บใน Keychain ของ Mac
- ล็อก (`~/Library/Logs/Dolmetscher/engine.log`) มีข้อความสนทนาเฉพาะเมื่อใช้ `--log-text`
- ประวัติการสนทนาปิดเป็นค่าเริ่มต้น ประกอบด้วยข้อความ ไม่มีเสียง เก็บใน `history.sqlite` แบบไม่เข้ารหัส (สิทธิ์ไฟล์ 0600) และจะอยู่ในข้อมูลสำรองด้วย ลบด้วย `--history-purge N` หรือ `--history-clear`

## Mac: สิ่งที่ออกจากเครื่อง

- **ข้อความที่รู้จำได้** (ไม่ใช่เสียง) ส่งไปที่ Google Translate เพื่อแปล สำรอง MyMemory แบบ POST ในเนื้อหาคำขอ เมื่อเปิดการแปลด้วย Claude ข้อความพร้อมประโยคก่อนหน้า (ค่าเริ่มต้น 8 ประโยค) และอภิธานศัพท์จะส่งไปที่ Anthropic
- **ข้อความที่แปลแล้ว** ส่งไปที่ Microsoft (edge-tts) เพื่ออ่านออกเสียง ถ้าใช้ `--tts say` หรืออยู่ออฟไลน์ เสียง macOS ในเครื่องจะอ่านและไม่มีการส่งข้อมูล
- **การแปลย้อนกลับ** (ค่าเริ่มต้น: ปิด) ส่งประโยคที่แปลแล้วไปที่ Google Translate เพิ่มเติม
- ตอนเริ่มจะมีคำขอทดสอบสั้นๆ ("hi") ไปที่ Google หรือ Microsoft โดยไม่มีเนื้อหาสนทนา **โหมดส่วนตัว** (`--private` ค่าเริ่มต้น: ปิด) จะไม่ส่งคำขอนี้ และไม่ย้อนไปใช้คำขอที่มีข้อความอยู่ใน URL
- Python แพ็กเกจ และโมเดลถูกดาวน์โหลดจาก Astral, PyPI, Hugging Face และ GitHub ระหว่างติดตั้ง ไม่มีเนื้อหาสนทนาถูกส่ง
- ไม่มีสวิตช์ "ห้ามส่งข้อมูลเลย"

## iPhone

- การรู้จำเสียงพูดทำบนอุปกรณ์ เสียงไม่ถูกส่งและไม่ถูกบันทึก
- ตัวแปลออนไลน์ (เฉพาะเมื่อเปิด "Online translator as fallback"): Google Translate แบบ POST ในเนื้อคำขอ หาก Google ยังไม่ตอบใน 1.2 วินาที MyMemory จะเริ่มทำงานพร้อมกัน (แบบ POST เช่นกัน) ข้อความจึงไปที่ทั้งสองบริการชั่วครู่ และไม่อยู่ใน URL
- ประวัติเก็บในเครื่องที่ `history.json` ค่าเริ่มต้น 30 วัน (ปรับได้ 0 คือปิด) ล็อกด้วย Face ID ได้ "Delete all data" อยู่ในการตั้งค่า
- ตำแหน่งที่ตั้งใช้เฉพาะหน้าจอ "Help now" และแอปไม่บันทึกหรือส่งออก
- แอปดาวน์โหลดโมเดล Whisper เมื่อคุณแตะ "Download model" เท่านั้น (จาก Hugging Face)

## เบราว์เซอร์

- ก่อนเริ่มไมโครโฟนครั้งแรก หน้าเว็บขอความยินยอมหนึ่งครั้ง
- Chrome ส่งเสียงไปที่บริการรู้จำเสียงของ Google, Safari ส่งไปที่ Apple Pause และ Stop จะหยุดการรู้จำทั้งหมด
- ข้อความที่รู้จำได้ไปที่ Google Translate สำรอง MyMemory แบบ GET ข้อความจึงอยู่ใน URL
- มีเพียงเบราว์เซอร์ที่เก็บข้อมูล (`localStorage`): การตั้งค่า ความยินยอม แฟลชการ์ด และอื่นๆ รายการสนทนาจะหายเมื่อปิดหน้าเว็บ
- หน้าเว็บไม่โหลดสคริปต์ของบุคคลที่สาม
