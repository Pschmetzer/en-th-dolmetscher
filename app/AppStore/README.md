# Mac App Store texts (draft)

Store listing drafts for the **Mac app** in en-US, de-DE and th. The iPhone app has its own texts in [`ios/AppStore/`](../../ios/AppStore/).

| File | Limit |
|---|---|
| `name.txt` | 30 characters |
| `subtitle.txt` | 30 |
| `keywords.txt` | 100 |
| `description.txt` | 4000 |

Status: the Mac app is not in the Mac App Store and there is no App Store build yet (it is built from source with `build.sh`). These texts are drafts for later. en-US is the source text; de-DE and th are machine-translated and **must be reviewed by native speakers** before they are used. Keep them in line with the README and [docs/DATENSCHUTZ.md](../../docs/DATENSCHUTZ.md) when features change.
